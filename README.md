# ¿Quieres salir conmigo?

Landing interactiva para invitar a una cita.

## Desarrollo local

```bash
npm install
npm run dev
```

Para probar en móvil (misma WiFi):

```bash
npm run dev -- --host
```

## Personalizar

Edita `src/config.ts` (WhatsApp, textos, días, planes e imágenes).

## Deploy

El sitio se publica automáticamente en GitHub Pages al hacer push a `main`.
